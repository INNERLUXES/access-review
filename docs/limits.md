# What the review does not see

- **Access outside the files.** Shared accounts, database logins, direct cloud console access and anything granted outside the role model are not in the export, so they are not in the review.
- **Whether access is used.** A permission held but never used looks the same as one used every day. Usage logs answer that; this tool does not read them.
- **Timing.** The review is a snapshot of the day the files were exported. A person who left and came back, or a role granted for one day, is not visible.
- **Rules you did not write.** A conflict is found only if a rule describes it. The tool has no built-in list, because the right list depends on the process.
- **Names that do not match.** If the application and HR use different user names, every person looks like an unknown account. Map the names before the review.

The report is a list of things to look at, not a verdict on anyone's access.
